# Japanese Sentence Structure - Self-Study App

## Features
- 35 Essential Patterns - Core to advanced sentence structures
- Furigana Toggle - Show/hide reading aids for all kanji
- Translation Toggle - Show/hide English translations
- TTS - Text-to-speech for pronunciation practice
- Flashcards - Digital flashcard study mode
- Quizzes - 4 quiz modes
- Vocabulary - Searchable lists with furigana
- Grammar - Detailed explanations
- Printable Cards - 1 pattern per page

## Quick Start
1. Open index.html in any modern browser
2. Study patterns in the Learn tab
3. Test yourself with quizzes
4. Print cards for offline study

## Customization
Edit js/data/MasterDictionary.js to add your own patterns, vocabulary, and quiz questions.
